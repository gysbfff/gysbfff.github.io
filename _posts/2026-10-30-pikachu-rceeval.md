## 题目: Pikachu RCE - exec "eval"

## 题目描述
页面提示提交一个字符串。后端使用 PHP 的 `eval()` 函数直接执行用户输入。要求利用代码执行漏洞，执行任意 PHP 代码。

## 解题思路
`eval()` 函数会将传入的字符串作为 PHP 代码执行。由于未对输入做任何过滤，攻击者可以直接写入任意 PHP 代码，甚至通过 `system()` 等函数进一步执行系统命令。

## 解题步骤
**1. 执行 PHP 代码验证**
* 在输入框输入：`phpinfo();`
* 提交后页面弹出了详细的 PHP 配置信息页面（PHP Version 7.3.4），证明代码执行成功。

**2. 读取系统文件**
* 输入：`echo file_get_contents("C:/Windows/win.ini");`
* 页面成功回显了 Windows 配置文件的内容，证明可以通过 PHP 函数读取服务器本地文件。

**3. 执行系统命令（终极绝杀）**
* 输入：`system("whoami");`
* 页面成功回显了当前系统用户名（如 `laptop-3r0vf5g1\25047`），证明通过 `eval` 执行 PHP 代码，可以进一步直接控制操作系统。

## 知识点总结
1. **代码执行与命令执行的区别**：命令执行（如 `exec`）调用的是系统命令；代码执行（如 `eval`）执行的是编程语言代码（如 PHP）。
2. **`eval()` 的危险性**：它可以把字符串当作代码解析执行，是 PHP 中最危险的函数之一。现代 PHP 开发中应严格禁用或避免使用。
3. **防御策略**：
   * 避免使用 `eval()`、`assert()` 等危险函数。
   * 对用户输入进行严格的白名单校验。
   * 部署 WAF，拦截包含 PHP 代码特征的请求。
