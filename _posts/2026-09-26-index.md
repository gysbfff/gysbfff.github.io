# 题目： CTFHub Git泄露 Index

## 题目描述
页面输出 Where is flag? ，存在.git目录泄露。
flag执行过 git add ，但是没有执行git commit提交，保存在git index暂存区，不在提交日志，也不在stash贮藏区。
 
## 解题思路
git index（暂存区 / stage）是工作区和版本库中间的缓冲区。文件执行 git add 之后进入index，还没有commit，不会出现在 git log 历史记录，也不属于stash。
下载泄露的.git仓库，读取index暂存区内容拿到flag。

## 解题步骤
1. 在靶场地址后添加/.git/HEAD,确认该题为Git泄露
2. win+R 打开powershell，运行git-dumper"靶场地址/./git"./git_out3
3. 进入git_out3文件夹，shift+鼠标右键打开Git Bash
4. 输入git log,执行完后执行回滚命令 git reset --hard +add flag哈希
5. 返回文件夹打开txt文件获取flag

## 知识点总结
1. 三种Git泄露快速判断
-git log能看到add flag →  git reset --hard 哈希 （本题）
-git log看不到， git stash list 有输出 →  git stash show -p stash@{0} 
-log、stash都空 → index暂存区， git show :0:index.php
2. Git源码泄露专题小结
-漏洞成因
 网站部署时，把`.git`文件夹直接暴露在web目录下，攻击者下载整个git仓库，恢复历史文件拿到flag。
-工具
 git‑dumper，用于下载被泄露的.git仓库。
 ```powershell
 git‑dumper "url/.git/" ./输出文件夹
3. 防护
  上线网站不要把 .git 目录放到web可访问目录；部署时删除.git文件夹；web服务器禁止访问 .git 开头路径。
