# 题目： Bugku CTF 入门逆向 
 
## 题目描述 
题型：Reverse 逆向
难度：入门
附件： file.zip ，解压得到32位可执行程序  baby.exe 
题目描述
运行  baby.exe  只会输出普通提示语句，不会直接打印flag，需要通过静态分析程序逻辑，挖掘隐藏在程序内部的flag。
## 解题思路
1. 本题 flag 不是明文存储在字符串区，无法直接搜索字符串得到。
2. 程序在  main  函数中，通过大量  mov  指令逐字节将flag的ASCII码压入栈中。
3. 在线反编译工具的伪C代码会自动优化栈指令，导致看不到明文，需要提取汇编中的十六进制ASCII码。
4. 使用 Python脚本批量解码ASCII码，拼接得到完整flag。

## 知识点总结
1. 栈上赋值的flag无法通过字符串搜索找到，只能分析汇编指令。
2. 在线反编译平台存在代码优化，伪代码 ≠ 完整程序逻辑，有局限性。
3. CTF入门逆向常考：逐字节ASCII硬编码、栈局部变量存储秘密数据。
4. Python  chr()  函数是逆向、密码学中 ASCII 解码的常用方法。
## 做题反思
新手容易依赖伪代码和字符串检索，忽略底层汇编逻辑。本题让我掌握了：看不到数据不代表没有数据，栈内存往往藏着关键信息。
