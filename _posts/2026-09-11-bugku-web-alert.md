# Bugku CTF alert 签到题
## 题目信息
- 平台：Bugku CTF
- 题目名称：alert
- 难度：Web入门
- 考点：查看网页源代码、HTML注释、HTML十进制实体编码解码

## 题目描述
访问页面就持续弹出alert弹窗，需要找到页面中隐藏的flag。

## 解题思路
访问页面后会不断弹出alert弹窗，直接浏览页面无法找到flag。
但是alert弹窗不会影响网页源代码读取。flag写在HTML注释内部，并且使用HTML十进制实体编码`&#数字;`保存。
我们只需要查看网页源码，提取注释内的编码字符串，再对HTML实体解码，就能拿到flag。

## 解题步骤
1. 打开题目页面，页面持续弹出alert弹窗，**不要点击弹窗的确定**。
2. 使用快捷键 `Ctrl + U` 打开网页源代码。
3. 滚动到源码最底部，找到HTML注释内容：
```html
<!-- &#102;&#108;&#97;&#103;&#123;&#97;&#57;&#48;&#52;&#100;&#99;&#97;&#55;&#101;&#56;&#48;&#57;&#50;&#100;&#102;&#50;&#51;&#52;&#51;&#50;&#56;&#50;&#57;&#54;&#53;&#97;&#50;&#51;&#55;&#57;&#98;&#51;&#125; -->
4.提取注释中间的编码字符串，使用python进行HTML实体编码。python本地解码代码：
from html import unescape

html_code = '&#102;&#108;&#97;&#103;&#123;&#97;&#57;&#48;&#52;&#100;&#99;&#97;&#55;&#101;&#56;&#48;&#57;&#50;&#100;&#102;&#50;&#51;&#52;&#51;&#50;&#56;&#50;&#57;&#54;&#53;&#97;&#50;&#51;&#55;&#57;&#98;&#51;&#125;'
result = unescape(html_code)
print("解码结果：", result)
