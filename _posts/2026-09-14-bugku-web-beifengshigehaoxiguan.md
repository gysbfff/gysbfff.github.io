# 题目: 备份是个好习惯

## 题目描述
Web基础审计题目，页面会输出两段MD5值，需要构造特殊参数绕过代码逻辑，最终获取flag。
题目名字暗示考点：网站存在备份文件泄露。
 
## 解题思路
### 本题包含两个核心考点：
1. .bak 备份文件源码泄露，获取完整 PHP 源代码
2. 代码审计 + 双写绕过过滤 + MD5 数组弱类型绕过
## 解题步骤
1. 利用备份泄露获取源码。题目提示“备份”，CTF 常见备份后缀为  .bak 。
直接在 URL 后访问：/index.php.bak
下载备份文件，得到完整源码：<?php
include_once "flag.php";
ini_set("display_errors", 0);
str = strstr(_SERVER['REQUEST_URI'], '?');
str = substr(str,1);
str = str_replace('key','',str);//①会把所有的key字符串删掉
parse_str($str); //②把所有字符串解析成GET参数
echo md5(key1);
echo md5(key2);
if(md5(key1) == md5(key2) && $key1 !== $key2){
echo $flag."取得flag";
}
?>
PHP特性：md5不能处理数组，传数组进去不会报错，直接返回 NULL 
- md5(数组1) = null
- md5(数组2) = null
 null == null  → ✅ 成立
而两个不同数组  $key1 !== $key2  → ✅ 成立
👉 在url里  kekeyy1[]=1  代表把kekeyy1定义成数组！


1. 分析代码过滤规则
关键代码：
```php```
$str = str_replace('key','',$str);
功能：删除所有字符串中的 key
如果我们直接传入  key1 ，会被删成  1 ，无法生成  $key1  变量。
2. 构造双写绕过
绕过技巧：双写 key
- 传入  kekeyy1 
中间的  key  被删除 → 剩下  key1 
- 传入  kekeyy2 
中间的  key  被删除 → 剩下  key2 成功绕过过滤，生成  $key1 、 $key2 。
4. 分析 MD5 绕过条件
 题目判断条件: md5($key1) == md5($key2) && $key1 !== $key2
-要求：
 1. 两个 MD5 值相等（弱类型 ==）
 2. 两个变量不完全相同（强类型 !=
5. 利用 PHP 数组漏洞绕过
PHP 特性：
 - md5 不能加密数组 ——————md5函数设计初衷：给字符串做哈希加密。如果你丢进去一个数组，md5处理不了，不会报错，直接返回NULL
 - 传入数组会返回 NULL
 - NULL == NULL 成立
 - 两个不同数组 !== 不成立
 完全满足题目条件！
 URL 中  []  代表数组，最终 Payload：?kekeyy1[]=1&kekeyy2[]=2
最终访问链接为: http://160.202.254.160:17231/?kekeyy1[]=1&kekeyy2[]=2

### 为什么访问 /index.php.bak
`.bak` 是代码编辑器自动生成的备份文件。开发人员编写`index.php`时，编辑器会自动生成`index.php.bak`备份副本。
如果服务器没有限制访问该文件，攻击者可以直接访问该地址，下载原始PHP源码。
访问`index.php`会执行PHP脚本，只能看到页面输出；访问`index.php.bak`服务器不会解析执行，直接返回原始源代码。
本题题目名称「备份是个好习惯」，就是提示该漏洞。
-补充小坑
不是所有网站都有bak文件，这是题目故意留的漏洞。真实环境中，运维会配置不让访问bak、swp这类备份文件。

## 核心知识点总结
1. 备份文件泄露： .bak 、 .swp 、 .txt  是 Web 高频泄露点
2. 关键词删除绕过：被过滤关键词可使用双写绕过
3. MD5 弱类型绕过：数组传入 md5 返回 null
4. == 和 === 区别
-  ==  只比较值，不比较类型
-  ===  值和类型必须完全一致
5. parse_str()：可自动将 URL 参数解析为 PHP 变量
6. 数组就是一个容器，可以一次性存放好多个数据的变量。
简单区分
 - 不带[]：普通字符串  kekeyy1=1 
- 带[]：数组  kekeyy1[]=1
7. PHP弱类型
PHP属于弱类型语言，`==`为弱类型比较符号：比较前会自动转换两边的数据类型，只对比数值是否相等，不校验数据类型。
而`===`是强全等，要求**值相等并且数据类型完全一致**。
本题使用`md5($key1) == md5($key2)`进行弱类型判断，两个数组传入md5后都返回null，`null == null`结果为真，成功绕过第一层校验；再通过`$key1 !== $key2`判断，两个独立数组不完全全等，满足第二个条件。
