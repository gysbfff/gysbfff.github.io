# 题目：[+-<>]

## 题目描述
Crypto，直接给出一段由`+ - < > [ ] . ,` 组成的字符串，是Brainfuck代码。1

## 解题思路
Brainfuck是极简的编程语言，只有8条指令，运行代码输出ASCII字符得到字符串flag。
两种解法：在线BF解释器执行/ Python本地编写BF解释器运行。

## 解题步骤
1. 复制题目里完整的BF代码。
2. 使用BF在线解释器，粘贴代码。
3. 点击Run执行，得到flag:flag{0d86208ac54fbf12}

## Brainfuck指令表
 | 指令 | 含义 |
 | ---- | ---- |
 | `>` | 指针向右移动一格 |
 | `<` | 指针向左移动一格 |
 | `+` | 当前格子数值 +1（0~255，超过就循环） |
 | `-` | 当前格子数值 -1 |
 | `.` | **输出当前格子数字对应的ASCII字符**（输出文字，解题核心） |
 | `,` | 读取一个输入字符，存入当前格子 |
 | `[` | 如果当前格子是0，直接跳到对应的`]`后面 |
 | `]` | 如果当前格子**不是0**，跳回对应的`[` |

## 知识点总结
 Brainfuck是图灵完备的极简编程语言，仅8个指令。CTF密码题常直接给出BF代码，运行后输出flag；也会出现变种，例如Ook!。
