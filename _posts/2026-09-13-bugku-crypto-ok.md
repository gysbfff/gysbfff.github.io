# 题目: ok

## 题目描述
 Crypto 密码学题目，题目描述Ook，提供附件下载。
 
## 解题思路
 Ook! 是 Brainfuck 的趣味变种编程语言，只用 `Ook.` `Ook!` `Ook?` 三种符号，成对组成指令。
-解题核心：将Ook代码进行解释执行，输出明文flag。
-两种解法：在线Ook解释器 / Python本地编写Ook解码器。

## 解题步骤
1. 下载题目附件，使用记事本打开文件，复制全部Ook代码。
2. 打开Ook在线解释网站，将密文粘贴到输入框。
3. 点击 `Ook! to Text`，网站执行代码，直接输出flag。
4. 将flag提交到Bugku平台，完成题目。

## 知识点总结
1. Ook!是Brainfuck语言的趣味变体，指令由两个Ook一组构成，一共8种组合，对应Brainfuck的8条指令。本质是对Brainfuck代码做了文本包装。
2. Brainfuck（简称BF）
 -Brainfuck 是一种极简的编程语言，只有8条指令，设计初衷就是用来玩、做趣味加密，不是用来写正经软件，CTF密码题里经常出现。
| 指令 | 含义 |
| ---- | ---- |
| `>` | 指针向右移动一格 |
| `<` | 指针向左移动一格 |
| `+` | 当前格子数值 +1（0~255，超过就循环） |
| `-` | 当前格子数值 -1 |
| `.` | **输出当前格子数字对应的ASCII字符**（输出文字，解题核心） |
| `,` | 读取一个输入字符，存入当前格子 |
| `[` | 如果当前格子是0，直接跳到对应的`]`后面 |
| `]` | 如果当前格子**不是0**，跳回对应的`[` |
